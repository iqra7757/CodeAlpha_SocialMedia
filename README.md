# CodeAlpha Social Media Platform 🚀

This is a YouTube-inspired social media application developed during my internship at **@CodeAlpha**.

## 📌 Features Implemented:

* **Subscription System:** Real-time subscribe/unsubscribe using AJAX.
- **Video-style Grid:** Posts are displayed in a professional grid layout.
- **Sidebar Navigation:** Home, History, Liked Content, and My Posts are fully integrated.

## 🛠️ Tech Stack:
- **Backend:** ASP.NET Core MVC
- **Database:** SQL Server (Entity Framework Core)
- **Frontend:** Bootstrap 5, FontAwesome, JavaScript (AJAX/Fetch)
